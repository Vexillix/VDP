# 图片字幕生成器

一个用于在图片上添加多行字幕的网页工具，支持实时预览和自定义样式设置。

## 功能特性

- 📸 图片上传和预览
- 🎨 丰富的字幕样式配置（字体、颜色、大小等）
- ✂️ **每行字幕独立背景块，呈现清晰的切割感**
- 👁️ 实时预览效果
- 💾 一键保存生成的图片

## 使用方法

1. 在浏览器中打开 `index.html`
2. 点击"选择图片"上传图片
3. 配置字幕样式和内容
4. 实时预览效果
5. 点击"生成字幕图片"生成最终效果
6. 点击"保存图片"下载到本地

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- Canvas API 进行图片和文字渲染
- 无需服务器，可直接在浏览器中运行

## 文件说明

- `index.html` - 主页面
- `styles.css` - 样式文件
- `script.js` - 核心功能脚本
- `prd.md` - 产品需求文档

## 浏览器支持

支持所有现代浏览器（Chrome、Firefox、Edge、Safari 等）
